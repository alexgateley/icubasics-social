🚑 CEN practice: the code clock
Rhythm check every 2 minutes, epinephrine 1 mg every 3–5. Nonshockable: epi as soon as you can. Shockable: shocks first, then epi.
At handoff, get the last epinephrine time so the clock keeps running.
